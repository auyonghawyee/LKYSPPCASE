# Dakota Crescent: An Interactive Case Study

An interactive, mobile-first scrollytelling site built for a Lee Kuan Yew
School of Public Policy (LKYSPP) case study workshop, adapting the case
*"From Humble Homes to Built Heritage: The Case of Saving Dakota Crescent"*
(LKYSPP Case Insights Unit, 2020) into a format designed to be read on a
phone during a live, facilitated session.

> This site is intended for classroom use within LKYSPP and is made
> publicly accessible solely so that workshop participants can view it
> on their own devices.

## What this is

Dakota Crescent was one of Singapore's last surviving pre-independence
public housing estates — built by the Singapore Improvement Trust in 1958,
threatened with full demolition in 2014, and partially conserved in 2017
after a ground-up heritage campaign. The case is used to teach the tension
between urban redevelopment and heritage conservation in land-scarce
Singapore.

Rather than distributing the case as a PDF, this site presents it as a
single continuous scroll: historical and institutional context, primary
source documents (an actual relocation notice, a campaign Facebook group,
photographs of the estate), first-person accounts of residents affected by
the move, and a role-based stakeholder briefing (residents, HDB, and
heritage advocates) that students are assigned before a small-group
discussion.

The scroll deliberately pauses before the case's resolution — visitors are
asked to make a call (conserve, or redevelop) before a button reveals what
was actually decided, and how residents' lives turned out afterward.

## Why a microsite instead of a written case

This was an experiment in workshop pedagogy: whether a paced, interactive
format could get a room of public policy students to engage with a case
more actively than a shared PDF read in advance. It's built to be handed
out by QR code at the start of a session, read individually, and then
paused for live discussion — not to replace the underlying written case,
which remains the authoritative source.

## Built with

Static HTML, CSS, and vanilla JavaScript — no build step, no external
dependencies beyond Google Fonts. All images are embedded directly in the
page so it works offline once loaded.

## About the Case Insights Unit

The [Case Insights Unit](https://lkyspp.nus.edu.sg/research/case-insights-unit)
at LKYSPP produces public policy case studies on contemporary issues across
Asia and runs an annual student Case Writing Competition.
